# Vision

## Vision

Build the best offline AI assistant for software developers.

The assistant should understand projects instead of only answering questions.

It should help developers understand, maintain, document, improve, and navigate software systems while keeping all source code private.

---

## Mission

Enable every developer to work with AI without sending their source code to the cloud.

---

## Core Values

- Privacy First
- Offline First
- Transparency
- Extensibility
- Developer Experience
- Long-Term Maintainability

---

## Long-Term Vision

Become the developer's second brain.

Not another chatbot.

An intelligent software engineering companion.
